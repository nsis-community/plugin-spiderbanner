## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-spiderbanner/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `SpiderBanner.dll` to `Plugins/<variant>/`.
